The benchmark creates 1, 12 and 120 stations × 365 days × 24 hourly readings. It compares a one-pass Python dictionary, pandas groupby and SQL GROUP BY and asserts the results agree. SQL timing includes loading into the in-memory database. cProfile saves its top cumulative-time functions to output/profile.txt. Python loops are transparent, pandas is concise and vectorised but uses RAM, SQL suits repeatable queries and persistent storage. Running sums/counts take O(n) time and O(station-days) space; storing all rows first takes O(n) input space.
